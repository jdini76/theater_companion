## Suggested title

RehearseLines Tutorial 01 | Run Lines on Your Own

## Suggested description

Need to practice a scene without a scene partner? In this introduction to RehearseLines, we'll set up a sample production called The Clockwork Curtain, import an original scene, assign a character voice, and start a rehearsal.

You'll also see where productions and scripts are stored, why a fresh browser starts with an empty list, and where to find the tools for transferring a production. We'll cover the transfer process in a future tutorial.

Try RehearseLines at https://www.rehearselines.com/
